## 1. Counting convention

An **active formula** is a numbered `F-<system>-001`-or-higher identifier carrying a computational, analytical or governance entry, excluding:

- the `F-<system>-000` register-rule series, which carries governance conventions rather than formulas;
- the one retired identifier `F-WEP-048`;
- sub-part letters used inside another formula's heading (for example `F-DP-006a`/`F-DP-006b` inside `F-DP-006`).

A lettered identifier that defines its own separable computation (`F-EC-002a`) **is** counted; a lettered identifier that names a sub-part of one heading (`F-DP-006a`, `F-DP-006b`) is not.

## 3. Status and authority vocabulary used in this inventory

| Status | Meaning in this inventory |
|---|---|
| `OWNER-APPROVED VALUE` | An explicit owner decision approves the numerical value. None is recorded for any formula in these nine registers. |
| `PROVISIONAL VALUE` | A working value exists but is uncalibrated. The register states it is provisional or requires Prompt 14 calibration. |
| `DESIGN PROPOSAL` | A value or arithmetic model proposed but not adopted as a confirmed rule. All eight B-09 formulas fall here. |
| `NEEDS PLAYTESTING` | A value cannot be settled without actual player behaviour or sustained operation. |
| `UNSPECIFIED` | No numerical value exists, the formula is structural, or the value is owner-reserved and undefined. This is an absence marker, not a fifth status. |

The **numerical authority** column names who may decide or approve the value. It is deliberately separate from the registering system and from the validator.

## 8. Cross-reference and definition-integrity findings

1. **B-07 `F-TM-000e` cites `§4.20`, which does not exist.** The B-07 register has §4.1–§4.9; the submission-check section is not numbered 4.20. The timing rule itself is unambiguous, but the citation is stale. Recorded, not edited.
2. **B-07 duplicate register-rule identifiers** `F-TM-000e` and `F-TM-000f` — see §2 finding 4.
3. **B-04 `F-EC-036`…`F-EC-046` are non-computational** yet count as active formula identifiers — see §2 finding 5.
4. **B-12 formulas carry no timing or phase field.** The register specifies rule-level boundaries but no P0–P7 position per formula. This is a genuine metadata gap for `F-FP-001`…`F-FP-016`, important because B-12 sanctions interact with boundary resolution.
5. **B-09 formulas carry no operator- or platform-set numerical defaults.** Their values are candidate values pending `UD-040`, `UD-043`, `UD-044` and `UD-046`; where the register states a 0% attribution fallback, that fallback is provisional and reversible.

## 9. Maintenance rule

A change to any of the nine registers requires a matching edit here in the same pass: add, retire or re-classify the record, update the reconciliation table and re-run the 14A validator. This document may never introduce a formula, expression or value that the owning register does not state.

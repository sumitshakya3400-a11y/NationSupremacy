**Checksum convention.** Each SHA-256 is computed over the exact bytes of the archived file as stored (UTF-8). The R6 and R7 archives use LF (`\n`) newlines (0 CRLF); reproduce with `python -c "import hashlib,pathlib;print(hashlib.sha256(pathlib.Path('<file>').read_bytes()).hexdigest())"` or `sha256sum <file>`. No newline normalization is applied to the recorded digest; the digest is of the stored bytes.

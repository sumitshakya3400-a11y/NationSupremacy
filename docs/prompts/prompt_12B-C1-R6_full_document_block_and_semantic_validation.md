### DEFECT 4 — HISTORICAL CLASSIFICATION RELIES TOO HEAVILY ON KEYWORDS

R5 can mistakenly treat a stale assertion as historical merely because its sentence contains the word `historical`.

This is unacceptable.

The following must be rejected:

`Historical note: the formula register now contains only FP-P01–FP-P12.`

The word `historical` does not make the current-state assertion historical.

Required correction:

Implement a reliable contextual classification model.

Distinguish:

1. Current authoritative assertions.
2. Genuine historical records.
3. Explicitly superseded records.
4. Explanatory mentions.
5. Canonical definitions.
6. Malformed or ambiguous assertions.

A genuinely historical record should have identifiable historical context, such as:

- An explicit date or version.
- A clearly described former state.
- An explicit statement that a prior representation was superseded.
- A historical subsection or record boundary.

These are examples, not an excuse to rely on one keyword.

A historical qualifier alone must not override present-tense or current-state assertions.

When a sentence contains both historical language and a statement describing the present state, evaluate the present-state assertion.

Examples:

- "The former register contained FP-P01–FP-P12 as of the earlier revision." — may be legitimate history.
- "Historical note: the register now contains only FP-P01–FP-P12." — current-state claim and must be validated.
- "The old list was superseded by the current FP-P01–FP-P14 collection." — legitimate explanation when consistent with the canonical source.

If a parameter-bearing statement in an authoritative current-state region cannot be classified unambiguously, fail closed with a meaningful diagnostic.

Do not solve ambiguous cases by silently ignoring them.

Do not eliminate legitimate historical information to make negative fixtures pass.

For example:

### Genuine historical references

Preserve statements that clearly describe a former state and do not assert it as current.

- Explicitly dated earlier parameter records.

- Historical comparison tables.
- Earlier accepted revisions.

- A discussion of a single formula parameter.

In non-authoritative explanatory sections, classify it according to an explicit and documented rule.
